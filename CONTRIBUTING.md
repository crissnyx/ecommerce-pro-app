# Contributing to E-Commerce Business Intelligence & Revenue Intelligence SaaS

First off, thank you for taking the time to contribute! 🎉 

This project is built to provide robust revenue intelligence, predictive sales forecasting, and automated operational alerts for DTC e-commerce SMBs.

## 🚀 Code of Conduct
By participating in this project, you agree to abide by its terms. Please keep all interactions respectful, professional, and constructive.

## 💻 How Can I Contribute?

### Reporting Bugs
If you find a bug, please create an issue containing:
- A clear description of the problem.
- Steps to reproduce it.
- Expected vs. actual behavior.
- Screenshots or logs if applicable.

### Suggesting Enhancements
Feature requests are always welcome! Open an issue describing:
- The rationale behind the suggestion.
- How it benefits DTC e-commerce merchants or operators.
- A proposed implementation or alternative approach if possible.

### Pull Requests
1. **Fork the repository** and create your feature branch from `main` (`git checkout -b feature/amazing-feature`).
2. **Make your changes**, keeping code clean, documented, and following Python best practices.
3. **Test your code** locally to ensure everything works smoothly.
4. **Commit your changes** using conventional commit messages (e.g., `feat: add new forecasting metric`, `fix: resolve data ingestion bug`).
5. **Push to your branch** (`git push origin feature/amazing-feature`) and open a **Pull Request**.
